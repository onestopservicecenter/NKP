# OSSC นครปฐม — เวอร์ชัน Pastel

เว็บไซต์ต้นแบบสำหรับ **ศูนย์บริการผลิตภัณฑ์สุขภาพเบ็ดเสร็จ (OSSC) สำนักงานสาธารณสุขจังหวัดนครปฐม**

## จุดเด่นของเวอร์ชันนี้
- ปรับหน้าตาเป็น **สไตล์พาสเทล** โทนมิ้นต์ ครีม ชมพูอ่อน ดูสะอาดและสบายตา
- มี **แบนเนอร์สไลด์** จากภาพหมวดงานที่ให้มา
- มี **9 หมวดงานหลัก**
- เมื่อกดแต่ละหมวด จะเปิด **หัวข้อย่อยภายในแต่ละ พ.ร.บ.** เช่น
  - ขั้นตอนการดำเนินงาน
  - ดาวน์โหลดแบบฟอร์ม
  - หลักเกณฑ์และกฎหมาย
  - คู่มือประชาชน/เจ้าหน้าที่
  - เอกสารเผยแพร่
  - ติดต่อสอบถาม
- มี **ระบบ Login เจ้าหน้าที่ / Admin**
- Admin สามารถเพิ่มผู้ใช้ กำหนดสิทธิ์รายหมวด และดูประวัติอัปโหลดได้

## ไฟล์สำคัญ
- `index.html` — โครงสร้างหน้าเว็บ
- `styles.css` — รูปแบบเว็บ (pastel theme)
- `app.js` — ข้อมูลหมวดงาน หัวข้อย่อย ระบบค้นหา และระบบทดลอง login/dashboard
- `assets/` — โลโก้ แบนเนอร์ และภาพปุ่ม LINE
- `backend/Code.gs` — โครงตัวอย่างสำหรับเชื่อม Google Apps Script / Google Drive

## วิธีแก้ไขหัวข้อย่อยแต่ละหมวด
เปิดไฟล์ `app.js`
- ข้อมูลหมวดงานอยู่ใน `RAW_CATEGORIES`
- โครงหัวข้อย่อยอยู่ใน `makeSubtopics(name)`

ถ้าต้องการแยกหัวข้อย่อยเฉพาะบางหมวดแบบละเอียดมากขึ้น สามารถเปลี่ยนจาก `makeSubtopics(name)`
เป็นการเขียน `subtopics` ของแต่ละหมวดแยกกันได้ทันที

## การอัปโหลดขึ้น GitHub Pages
1. สร้าง repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ root ของ repository
3. ไปที่ **Settings > Pages**
4. เลือก **Deploy from a branch**
5. เลือก `main` และโฟลเดอร์ `/(root)`
6. กด Save แล้วรอระบบเผยแพร่

## หมายเหตุ
- เวอร์ชันนี้เป็น **Frontend Demo + Local Demo Dashboard**
- หากต้องการใช้งานจริง ควรเชื่อมระบบกับ
  - Google Sheet (ข้อมูลผู้ใช้/สิทธิ์)
  - Google Drive (เก็บไฟล์เอกสาร)
  - Google Apps Script (ตรวจสอบสิทธิ์และอัปโหลดไฟล์จริง)
